# Native Surface Embedding

## Purpose and Scope

This CADGeometry component owns native spline chart embedding, whole adjacent
boundary reconciliation and chart-pair separation. Its parent is
[CADGeometry](../DESIGN.md). It has no children.

## Responsibilities and Boundaries

The existing native proof algorithms, local capacities, default limits and
failure contracts remain the authority. An immutable composing admission
receipt forwards source work, visited depth and retained slots to the caller.
The component never owns or resets the caller's cumulative allowance. Loft
owns the invocation counter shared with its original Coons path.

## Architecture

```text
caller invocation ledger
    -> immutable native admission callbacks
        -> native source preparation / retained proof fields
        -> local injectivity and touching-region cover
        -> adjacent seam algebra / chart-pair subdivision
    -> validated native surface or explicit failure
```

## Contracts and Invariants

Composing callbacks are admitted before work, cell visits and retained storage.
All validator continuations, opposite-boundary chart splits and exact seam
algebra keep the same receipt. Existing local capacities remain independently
binding; they never replace the caller's cumulative count. Legacy construction
without a composing receipt preserves its existing local-cap facade.
A cell's actual retained causal depth is supplied to the caller. Source caches,
proof data and copied control nets are not free preparation. Legacy Cartesian extraction is a construction image; its sampled rejection
check is not original-law authority for a positive embedding result. Proof cells
must retain selected original homogeneous laws independently. Reservation upper
bounds may overcharge bounded lower work; no refund, discount or lower private
allowance replenishes the caller's ledger.

Retained typed collection records reserve their actual `MemoryLayout<T>.stride`
in bytes before materialization, then convert bytes to canonical UInt32 words.
Original 64-bit slot reservations remain separate for legacy numeric buffer
sites. Index sorting, region hulls, cell records, differential field records and
paired-cell queues include their temporary collection copies; original local
cell-count ceilings remain unchanged by this byte accounting.

## State, Ownership, and Lifecycle

Admission callbacks are immutable Sendable values. The caller retains their
state owner; this component contains no mutable shared counter. Loft's source
and native paths reference the same Mutex owner on Native, WASM and Embedded.
There is no target-dependent raw state or unchecked isolation.

## Failure, Concurrency, and Constraints

Source rejection, nonfinite geometry, inability to prove embedding, subdivision
limits, storage/work exhaustion and cancellation remain explicit failures.
Callback failure propagates before the corresponding lower operation.

## Verification and Change Impact

Deferred behavioral checks must exercise unchanged native success/failure
fixtures, caller work and storage exhaustion before allocation, cumulative
opposite/adjacent continuations, retained depth and cancellation. Native, WASM
and Embedded compilation and runtime remain unperformed in the source-first
phase. Receipt wiring or source shape alone does not establish completion.

A native proof cell retains the original owning span and its exact homogeneous
polynomial. Cartesian extraction determines construction domains only. Tangent
and normal fields come from original quotient-rule numerators; stationary
boundary factors are removed only by exact all-coordinate division, with the
upper-boundary inward sign retained. Position bounds and pair residual nets
consume source-issued homogeneous receipts, including their original origin.

Adjacent chart orientation retains the caller's raw surface, original native
span indices, axis permutation and traversal signs. Oriented Cartesian charts
are candidates for scheduling only. Their rounded reversed knots cannot issue
original seam identity or differential authority. Whole original boundary
traversals are compared before any adjacent positive proof. Each native owner
is mapped affinely onto retained working labels; exact-real gain and station
enclosures preserve the source law across subdivision.

The adjacent global projection proof uses full original parameter frames for
both charts, with a normalized free traversal and consecutive transverse
unit domains. Native owner fields cover every actual knot cell. Candidate
reversed knots never issue these fields. The legacy touching-cell continuation
is admitted only when its free-axis scheduling knots represent the exact
original affine reversal and both working seam domains agree. Opposite halves
must retain the original source and clipped native domain, not a newly rounded
trimmed surface.

Before a candidate touching-cell continuation is used, every positive original
native owner intersecting the nominated original region must have a retained
source proof cell. Orientation rounding that collapses a scheduling span fails
this coverage admission; it cannot erase the original owner or permit a proof
on an incomplete source cover. Whole original projection admission precedes
this candidate scheduling branch and retains its independent complete cover.

The adjacent continuation decomposes the raw original surface before applying
axis permutations or reversals to candidate control nets. Transverse scheduling
uses the ordered original positive owner intervals and distinct ordinal labels
on each side of the seam. Thus no rounded reversed knot determines owner
existence. Each working interval retains its raw native bounds and exact-real
chart gain; only the candidate control-net order changes. Free-axis affine
station equality remains independently required by the current continuation.

The composing retention callback uses canonical UInt32 words (four bytes).
Existing native reservation sites still supply their intrinsic 64-bit slot
counts; the admission boundary checks and converts slots to two UInt32 words.
Raw byte reservations use checked ceiling division by four. Exact algebra
already supplies UInt32 words and bypasses the slot conversion. Causal shifted
receipts forward the same canonical callback once. Local native work/cell
ceilings keep their original values and units; retention accounting does not
replenish or raise them.

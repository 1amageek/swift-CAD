# Original Planar Curve Contact Partition

## Purpose and Scope

This child of [Curve Curve Contact](../DESIGN.md) owns complete exact contact
and overlap partitions for original nonperiodic native rational curves of
degrees one through three on one exact original plane. It has no children.
It is the shared lower receipt for planar drawing contours, wire repair and
native guide contact; it does not redefine the distance-tolerance contact API.

## Responsibilities and Boundaries

The producer owns complete selected-native span pair enumeration, exact plane
admission, isolated original parameter events, repeated/tangent contacts and
positive-dimensional original correspondence components. Original Root Span
owns source-bound scalar endpoint preparation. Rational Bivariate Algebra owns
finite ideals, complete real projection and branch incidence. This child also owns original exact side-localization and global signed ray
crossings for closed directed native contours. Consumers own arrangement faces,
editing policy and final spatial/topology publication.

## Architecture

```text
original native curves + exact plane + original closed trims + caller execution
    -> one preparation per positive native owner
    -> original homogeneous XYZ/W pair equations
    -> exact common component + finite quotient ideal
        -> complete real station/strip atlas
        -> isolated original pair roots
    -> retained source-bound endpoints on both curves + immutable partition
        -> contour/wire/guide consumer
```

## Contracts and Invariants

Every admitted original homogeneous control law lies exactly on the supplied
plane; tolerance-based projection is not planarity authority. Coordinate axes
are selected from its normal but exact original equations establish contact.
All positive native span pairs intersecting the original closed trims are
processed. Shared native endpoints retain their owning-side incidence.

The common original factor is divided exactly from both projected equations.
Its complete real atlas retains stationary fibers, isolated points, coordinate
components and station-to-strip incidence. The residual quotient ideal is
finite and is processed independently, so isolated contacts outside a common
overlap are not lost. Every retained pair root satisfies all original XYZ
cross-weight equations. Repeated roots retain their original source
multiplicities without claiming local intersection order from projection order.

Output event endpoints retain the actual selected source and native span.
Scalar coordinate transport consumes an already proved pair root. It never
replaces an algebraic endpoint with a nearest Double or restarts a system
solver. An overlap's rectangle bounds its correspondence; it does not claim
that every Cartesian pair in that rectangle coincides. Constant source pairs
retain their complete parameter rectangle explicitly.

Each source also publishes cuts ordered by exact parameter within each native
owner, including its original trim/native-boundary endpoints. Equal stations
merge event indices only within the same owner; adjacent owning sides remain
separate. Consecutive distinct cuts publish retained original root spans.
Ordering refines the existing scalar receipts under the same cumulative
execution, and never sorts using interval midpoints. These spans partition the
source parameter law; they do not by themselves classify an interval as an
overlap or authorize a contour winding result.

`mergeCuts` consumes the full caller-collected endpoint list for one original
source trim. Algebraic endpoints must retain that exact source/tolerance and
selected owner; authored points are assigned to every incident positive native
owner. Output cut provenance indices address the provided endpoint list. Its
source/native/trim boundaries and all supplied stations are covered, and the
result never claims new contact existence. All sorting and retained original
segment preparation reuse the same contact execution.

Outgoing sector order consumes retained original native segments at a common
exact spatial endpoint and the complete pair partitions covering them. Every
pair must be event-free in the open supplied segments. The producer transports
their retained scalar endpoint roots into one exact ordered field, translates
the original homogeneous laws, and proves a positive local radial interval by
complete Sturm counts of the original squared-distance derivative. A single
exact rational positive squared radius lies inside every such interval. Each
outgoing branch meets that circle exactly once; exact point cross-products
order the sectors, including stationary/cusp tangents. Equal circle points form
coincident groups only under the complete event-free contact partitions.
Neither a sampled angle nor an equal leading tangent proves sector order.

Directional overlap selection consumes the complete pair receipt and the two
merged source partitions. It requires every original pair/critical cut to be
retained by those merged partitions. Additional cuts are sliced against the
retained atlas; original station attachment and branch ordinals are reused.
Every resulting knot must bind exactly to cuts on both sources. Consecutive
knots identify complete source segments and the exact parameter direction;
the original derivative sign at a retained strip fiber confirms it. Missing
propagated cuts fail explicitly. Spatially constant native owners have no
directional physical edge and remain in the parent's complete contact receipt;
their exact original derivative-zero law must be proved before omitting them
from this directional result.

`prepareWinding` retains the immutable original native coefficients and closed
contour incidence once. Source preparation, output and all retained storage are
prepaid in the same caller execution. Each `sideWinding` consumes this token,
charges all actual query work, and never resets or discounts the parent ledger.
The contour/plane/tolerance binding remains immutable; only the original
coefficients and prior source admission are reused. The legacy source-taking
facade delegates to one preparation followed by the same query.

`sideWinding` consumes one complete merged original span, every original closed
contour, and complete pair partitions covering its source against every contour
source. An exact rational interior native parameter is chosen strictly between
its retained endpoints. Its exact nonzero original tangent defines a transverse
line. All original native owners are intersected with that line using complete
scalar Sturm roots; collinear owners retain their complete extrema and endpoints.
The nearest distinct signed line stations bound the two adjacent open sectors.
Two strictly interior exact rational stations therefore prove side localization,
without a numerical edge-normal probe. A constant owner is not a physical edge.

Global winding uses every original directed contour, including disconnected and
nested components. The producer chooses an exact rational ray direction excluding
all original endpoint stations. All native intersections are exact scalar roots;
only positive ray stations are counted. The first nonzero original derivative
at a root decides its crossing order, so even tangencies contribute zero and odd
crossings retain their sign. Whole ray-collinear owners and vertex-ray ambiguity
cause a different paid direction to be selected, never a silent default. Closed
contour incidence is proved from the original rational endpoint laws. The output
binds the original span, plane, full contour source and exact rational side seeds
with their signed winding counts. Consumers may propagate these counts through
arrangement adjacency, but cannot generalize the receipt to another source.

The receipt covers exact incidence only. An empty exact partition cannot
exclude contacts admitted by the parent's unchanged distance tolerance.
All work, exact words, native temporary bytes and actual output payloads debit
one caller execution before materialization. Source recursion, intrinsic
coefficient algebra and original pair/root subdivision remain distinct.

## State, Ownership, and Lifecycle

The receipt retains immutable original sources, trim/plane/tolerance binding,
original root endpoints and complete branch incidence. Derived atlas values
remain retained for consumers rather than re-solving a common component.
There is no mutable cache or platform-specific isolation difference.

## Failure, Concurrency, and Constraints

Invalid or nonplanar source, unsupported input degree/periodicity, cancellation
and exhausted original cumulative budgets fail explicitly. Failure publishes
no partial partition. Missing complete component authority is marked in the
actual branch and cannot produce a complete receipt.

## Verification and Change Impact

After the source phase, behavior must cover all degree pairs, positive rational
weights, tangencies, stationary/constant segments, continuous overlaps with
isolated residual contacts, endpoint/native-owner joins, orientation and
nonrepresentable scalar roots. The real drawing arrangement and wire repair
consumers must use the complete receipt, including failure/cancellation and
shared resource accounting. Source authoring is not behavioral evidence.

Event merging, monotone correspondence slicing, germ sectors and winding proofs
use the caller's independent exact algebra ceiling. The complete geometric
pair partition still uses its original subdivision ceiling. Both paths borrow
one execution; lexical context restoration preserves counters on failure.

## Direct Execution Ownership

Every actual partition, cut, overlap, germ and winding producer receives the
original exclusive execution. Original plane/source validation, exact algebra,
root ordering, closed-span preparation and output allocation consume it directly.
The invocation owner retains any persistent contribution; these producers never
create or translate an allowance. Scalar event roots and coefficient preparation
keep their independent proof axes and original source ownership. Ordinary and
direct consumers must retain exact selected trims and final cancellation.

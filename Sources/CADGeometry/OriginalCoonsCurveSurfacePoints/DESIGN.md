# Original Coons Curve-Surface Points

## Purpose and Scope
Child of [CADGeometry](../DESIGN.md), with no children. Owns complete isolated
Native curve/original Coons CS tuples and complete-empty coverage for one
aperiodic Native curve span and the existing bounded single-cell original Coons
issuer. Its four boundaries are authored finite directed traversals of direct
positive-weight aperiodic single-span Native curves. This is a bounded public
checkpoint, not complete Coons/procedural/seven-family intersection support.

## Responsibilities and Boundaries
The producer composes source preparation, exact native/requested domain
intersection, complete selected-cell classification and immutable point receipt.
It retains the existing original Coons law, four root spans, Native boundary
owners/maps and raw guarded relation. Existing algebra owns root search,
exclusions, incidence and tuple identity. The shared Native publisher owns
representative refinement and contact-kind reporting; the shared polynomial
normal helper differentiates the actual original homogeneous law. Root owns
result/ordinary/admitted rich/discrete dispatch and parent indexing. Existing
ruled and affine point APIs remain unchanged.

## Architecture
```text
Native curve + retained original Coons source + requested ranges + caller
  -> same Native allowance / source-degree and depth admission
  -> existing original Coons single-cell issuer + curveRelation
  -> exact native-requested intersection / raw XYZ equations + both W guards
  -> existing complete cells / every selected cell must be 0D / incidence
  -> shared normal from original H/W / shared Native point publisher
  -> readonly Coons source/coverage receipt + every exact T/U/V tuple
  -> root-owned ordinary/admitted rich/discrete result
```

## Contracts and Invariants
Tuple order is original Native curve T and original normalized Coons U,V.
Default ranges are the original finite closed curve span and [0,1]². Explicit
ranges intersect them exactly, including singleton endpoints. Disjoint ranges
retain original/native/requested domain arithmetic as exclusion evidence.
Otherwise the receipt retains the raw three equality laws, two nonzero W guards
and complete partition/incidence, including zero selected cells. Original
multiplicities, positive-weight denominators and directed maps remain unchanged.

Every selected cell is checked before any numerical point escapes. A positive
or mixed isolated/continuous relation fails atomically with nonDiscreteIntersection
on every public route. All 0D tuples remain in exact T/U/V order, including close
distinct roots or several UV preimages of one XYZ image. Candidate count bounds
parameter tuples. Undefined original normals or singular tangent vectors retain
the existing mixed classification; repeated roots use the existing contact-kind
contract. Tolerance controls representatives/contact kind, not equality or identity.

## Runtime Flows
One Native allowance pays for every source visit, exact Coons cell, raw relation,
closed-domain arithmetic, root/cell/coefficient visit, incidence, derivative
normal, scalar localization, numerical representative and retained output.
The single source product consumes caller subdivision depth zero. A positive
surface-to-boundary source level admits four direct Native leaves without
inventing further descent. Degree ceilings apply to the curve and all four Native
boundary inputs. Final receipt/result storage is followed by a zero-work
checkpoint and explicit cancellation before atomic result publication.

## State, Ownership, and Lifecycle
All published state is immutable Sendable. The receipt strongly retains the
original Coons value, four root spans, actual Native sources/indexes, directed
parameter maps/domains, exact original atlas/corners, target curve law, raw
relation, partition/incidence and isolation/localization owners. Point handles
retain their receipt and ordinal; foreign receipt access fails. Exact coordinates
retain field owners and inherited admission depth after inputs are released or
mutated. No new mutable cache or stored callback exists. Test counters use Mutex;
cancellation occurs outside the critical section on all targets.

## Failure, Concurrency, and Constraints
Periodic/multi-span curve inputs and Coons boundaries outside the lower issuer's
bounded direct-authored Native contract fail explicitly with callable English
incomplete markers and typed unsupportedCapability. Invalid source/tolerance,
work, checked UInt32 words/bytes, cell/algebra depth, source level, degree,
candidate/refinement limits and cancellation propagate without partial success
or legacy fallback after shape recognition. New temporary/output capacities and
receipt heap metadata are admitted before allocation. No retry, tensor fit,
replacement corner source or alternate solver is introduced.

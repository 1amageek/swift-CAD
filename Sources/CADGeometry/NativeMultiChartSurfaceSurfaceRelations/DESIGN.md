# Native Multi Chart Surface Surface Relations

## Purpose and Scope
Child of [CADGeometry](../DESIGN.md). Adapt finite closed nonperiodic positive-weight
Native B-spline surface products with multiple original spans to complete SSI
coverage. Periodic, pole and infinite domains remain separate requirements.

## Responsibilities and Boundaries
Geometry owns Native source meanings, chart tokens, exact source maps and canonical
right-side owners. The producer prepares source bindings and publishes the complete
result; it does not find roots or connect independently solved pairs. Existing
original algebra receives only original laws, sign predicates and domains. Original
incidence owns parameter connectivity. The lower SSI coverage contract owns retained
cell authority and exact image evidence; no numerical image merge establishes identity.

## Architecture
```text
ordinary / admitted / domain-pair / prepared SSI
 -> retained original closed chart covers and tensor source bindings
 -> original 4-UV laws + proved necessary ideal + right-owner DNF + raw rank witnesses
 -> one original common partition + incidence + connected components
 -> complete chart injection proof or piecewise original XYZ graph
 -> exact station fibers
 -> existing immutable relation/point handles + isolated numerical representatives
```

## Contracts and Invariants
All source-issued chart tokens and their closed domains are retained. Selection uses
lower-inclusive, upper-exclusive ownership on each nonfinal positive span and closes
the final native upper endpoint. Full closed incident-chart provenance remains distinct
from canonical publication ownership. Internal joins are C0 under original Native
validation; singleton selections select the right positive-span owner. Every selected
cell has exactly one canonical source chart, with its raw Jacobian rank and image law.
All original equations, guards, ordinal/unit sign mappings and boundaries remain retained.
Exact proportional normalization preserves negative sign direction. One global DNF
partition retains all UV tuples and original incidence across charts, including isolated,
positive and mixed components. Empty success proves the entire requested selection.

## Runtime Flows
Prepare both full native chart covers, charge the checked tensor chart product and
construct one common coverage. Publish every component; publish legacy points only
from wholly zero-dimensional components. Discrete routes reject any positive-dimensional
cell before publishing a subset. Every preparation, refinement, image graph, query and
final publication checks the same caller's cancellation and cumulative admission.

## State, Ownership, and Lifecycle
Immutable genuine common coverage retains both sources, original chart tokens/laws,
native/requested/effective domains, full partition, incidence, ranks and owner mapping.
Existing public handles retain their receipt. Exact stations retain their original field
owners and independent depths. There is no shared mutable state or target-dependent owner.

## Failure, Concurrency, and Constraints
Existing `maximumSeedCount` counts connected components. Span admission separately
limits each cover and the checked tensor product; the original execution charges all
exact cells, work and bytes cumulatively. No caps, tolerances or representative criteria
are widened. Source, span, work, storage, cell, algebra/coefficient depth, component,
refinement and cancellation failures are atomic.

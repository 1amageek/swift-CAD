# Original Boundary-Corrected Surface

## Purpose and Scope

This child of [Original Coons](../DESIGN.md) owns a generated native tensor
whose final four boundaries retain their original source laws. It has no
children. The correction is the causal source path for Hermite-constrained
Loft sides; it does not define new face continuity requests.

## Responsibilities and Boundaries

The source retains the original native construction and four original directed
traversals. It owns a quintic endpoint-flat transfinite residual law, selected
native preparation and whole requested-order interval differentiation. Loft owns
final G1/G2 target admission, embedding, side contacts and BRep publication.

## Architecture

```text
original native construction S + four retained original boundaries B
    -> once prepared native owners + construction boundary receipts

    -> final source embedding/continuity/BRep consumer
```

## Contracts and Invariants

The native construction occupies the actual normalized source square and has
exact C0 equality across all original native joins, admitted once by the issuer.
Whole embedding additionally requires the four retained boundaries' original
C0 authority; a derivative hull cannot certify a discontinuous position law. Every
boundary has the same immutable tolerance and exact original corner incidence.
Let h1(t)=10t^3-15t^4+6t^5 and h0=1-h1. The source is the construction plus
four boundary residuals blended by h0/h1 in the transverse coordinate, minus
the four corner residuals blended by products of the corresponding h functions.
This is an original real arithmetic law; no rounded native coefficient net is
claimed to preserve arbitrary exact products.

The two connector residuals must have exactly zero first and second derivatives
at the section ends. The issuer proves this from either unchanged original
traversal identity or a retained quintic endpoint connector whose construction
is the same complete original native boundary law. Consequently the original
construction's transverse section D1/D2 are preserved. Tangential section
coefficients come from the original boundary; continuity consumers must check
these final fields against their requested target, rather than inherit a prior
candidate certificate.

On an exact boundary, pure tangent coefficients are returned directly from the
retained original traversal, avoiding interval cancellation at incidence.
Section transverse D1/D2 coefficients are returned directly from the original
native construction after the endpoint-flat identity admission. Interior and
mixed coefficients retain the complete correction product rule.

Original selected native owners are prepared and stored once under caller work
and UInt32-word retention. Native bytes are converted with checked ceil(bytes/4).
All query scratch/work use the same caller callbacks; there is no private budget,
refund or reset. Source nesting is independent of subdivision. Source fields are
construction and original boundaries; preparation/corner residual caches and
caller capabilities do not change source equality or persistent fingerprints.

### Exact Rational Differential Atlas

For authored rational boundary charts, an immutable atlas composes each original
native homogeneous tensor with exact target-minus-native boundary residuals.
Both boundary partitions are intersected before combining their homogeneous
laws. The four corner residuals are evaluated from the same exact source pieces.
The quintic weights and all residuals share the actual native rectangle; quotient
rule tangent numerators and their cross product remain original polynomial
identity. This atlas supplies whole projection/normal sign proofs even when a
coordinate derivative vanishes at a closed parameter boundary. Angular or
algebraic endpoint substitutions require their own ordered-field atlas, and
cannot inherit this rational producer through cached interval coefficients.

## State, Ownership, and Lifecycle

All source and derived preparation are immutable. Copies retain the same value
owners. No target-specific mutable state or synchronization exception exists.

## Failure, Concurrency, and Constraints

Invalid source square, unequal corners, unproved endpoint-flat connector law,
missing original requested-order continuity, cancellation and caller exhaustion
fail explicitly. An interval midpoint never becomes original boundary authority.

## Verification and Change Impact

After source authoring, verify full boundary coincidence, D0/D1/D2 target
continuity before/after correction, differing native bases, nonrepresentable
endpoints, failure/cancellation/storage and public Loft embedding/pair contact.
No source packet, type declaration or build alone establishes these behaviors.

The retained native Taylor query accepts an optional explicit set of required mixed partials for the plane-derivative child. Only that set carries join-continuity authority; unused formal coefficients remain owner-wise enclosures. Omission retains the existing complete total-order guarantee.

# Capability Ledger

This ledger contains only capabilities registered by the current development
kernel. Future operations belong in [ROADMAP.md](ROADMAP.md) until a public
request, evaluator path, typed failure contract, and focused fixture exist.

A current capability is valid only when `KernelCapabilityCatalog.validate()`
can prove non-empty input, exact-output, public-API, failure-code, tolerance,
and fixture bindings. `KernelCapabilityContractTests` keeps the compiled
catalog and this ledger aligned.

All numerical geometry, topology, modeling, query, and exchange APIs require a
caller-supplied `ModelingTolerance` with distance, angle, and dimensionless
relative components; no source module declares an implicit
tolerance default. CI verifies this contract from the Swift parser AST and
restricts the standard preset to the named CADIR persistence boundary and
capability-envelope metadata.

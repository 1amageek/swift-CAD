retained-pcurve lift family, preparer, original graph producer and DI with complete
retained surface atlases. Native signatures and typed surface access remain intact;
that view shares immutable law/support arrays. No new position formula, inverse,

## Execution and receipt ownership

Swift 6.4.0 release and matching ordinary/Embedded SDKs are fixed by the admitted
compiler/SDK plans. Three focused paths execute on each target:

- Verify.py freshly compiles current independent source/adapters and DI0/DI with
  unchanged receipt-bound L0/L1 and numerical children. It executes literal retained
  hosts plus all existing independent/actual Native/periodic/finite lift regressions.
- VerifyActual.py freshly compiles a source/DI/numerical-adapter overlay against the
  original numerical lower ABI and tests actual boundary-correction construction,
  source issuance, lift graph, guarded DI and public numerical evaluation. A final
  fixture-only repair reuses successful adapter compilations only after exact command
  and generated-header/current-source correspondence, and recompiles each fixture.
  The unchanged numerical child cache is admitted from original Native and derivative
  receipts; only the unselected rolling-ball numerical branch is explicitly excluded.
- VerifyDepth.py reuses those current independent source/DI products and freshly links
  inherited-depth fixtures. It adds no source or lower-target rebuild.

All accepted input/product/log hashes match before and after runtime. Compiler/link
and depth-runtime deadlines are 120s; source/actual fixture runtime is 180s. Separate
scratch paths prevent overwritten artifacts. No CADCore/CADGeometry/Kernel or L2-L6
production target is rebuilt. ASAN instruments changed source/adapters/DI/fixtures;
retained numerical children are not instrumented, so this is not full-production ASAN.

## Behavioral evidence

- Literal weighted retained surfaces contain independent U=1/3 and V=1/2 cuts.
  Every closed pair side survives; nonmonotone rational, constant and reversed
  pcurves retain authored T/UV and complete fibers. A missing cell is refused.
- Same-UV chart sides with different original position laws remain separate;
  composition never invents C0 continuity or geometric identity.
- Exact singleton/strict/disconnected/empty requests are applied by the existing
  binder, with wrong-UV rejection, original parameter versus auxiliary layout,
  foreign owner refusal and retained source/cover lifetime.
- Actual zero-correction multi-cell and nonzero-correction surfaces use original
  boundary-issuer traversals, not newly constructed sameXYZ boundary curves. Exact
  graph positions equal independently expected source laws. Public point uses
  interval midpoints and is checked only against the existing numerical accuracy;
  its binary64 rounding is not the exact source-equality oracle.
- Actual affine/constant-U/V and reversed pcurves preserve all host cell incidents.
  Foreign host variants and tolerance-only out-of-support clamps fail explicitly.
- Preparation and incidence pass exact measured work/storage and fail at one less;
  entry/intermediate/final storage cancellation remains typed. Supplemental fixtures
  pass inherited value/coefficient depth at the attained ceiling and refuse one less
  during preparation and reuse; chart/source-depth limits are independently refused.
- Existing Native typed access and periodic arbitrary-size cycle/field/guard/source
  lifetime regressions execute again from current source. This is not M7 publication.

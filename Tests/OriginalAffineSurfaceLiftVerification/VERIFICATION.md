# Original affine pcurve surface-lift verification

This closes the affine, constant-U and constant-V pcurve supply/domain slice of
M4.S.LA/P.LA for finite nonperiodic Native surfaces. General/periodic surfaces,
other pcurves, priority images, tolerance-clamped support and lifted rolling-ball
consumers remain required open work. No full M4-M8 or whole-seven completion is
claimed; whole-seven remains 1/7 and full87 remains incomplete.

## Actual path and ownership

The affine pcurve source retains original origin, raw direction and authored
start/end coefficients. Exact normalized UV polynomials use the original formula,
including directed constant-U/V reversal. A retained-curve family verifies the
complete normalized support. The lift snapshot retains this source and the original
Native surface. Exact endpoint containment proves the whole affine segment stays
inside Native support; no rounded control-net proxy is introduced.

The Native lift source protocol preserves its bindings and Native chart key through
an additive common source requirement. Native and retained pcurve lift families use
one existing graph producer. T remains the sole authored parameter; UV are auxiliary
coordinates. Every closed surface/pcurve chart pair, equation, denominator and UV
bound survives. The additive retained domain issuer uses the existing graph binder,
exact selection, compatible coordinate import and retained original owners.

`Verify.py` assembles actual production source with imports-only transformations.
Retained-curve contracts absent from the old cache are compiled from current source.
Unchanged CAD children/modules/objects are admitted against the M6 receipts before
use. Existing Native lift `Proof.swift` is unchanged and executes against the new
shared producer with only its adapter-module import changed. Its original verifier
also includes the new common protocol when independently regenerated.

validation, complete child families, shared graph formula, DI restrictions, failure,
admission, lifetime, packages and all-target ownership. It found a concrete support
transfer bug: independently prepared compatible rational children were compared
without importing pcurve endpoints into the surface field. The actual red fixture
fails with incompatibleDomain in `Evidence/diagnostic-transfer-red`. Its pre-runtime
source/fixture hashes and command/log are retained; it is diagnostic, not acceptance.

before comparison/subtraction. All four final lanes confirm that finding and the
unchanged Native lift behavior. No remaining finding is known within this capability.
Initial missing assembly-dependency and fixture field-entry diagnostics, plus the
intermediate Native/ASAN/WASM runs, are not final acceptance.

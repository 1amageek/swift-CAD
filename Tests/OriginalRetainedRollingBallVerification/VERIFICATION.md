# Retained lift rails in the actual rolling-ball consumer

## Scope and implementation

The actual `OriginalRollingBallCurveSnapshotProvider` selects existing original
Coons/boundary-correction host providers and Native B-spline or retained
affine/constant pcurve providers. Four sealed capabilities, graph evidence and
coverage cases retain these bindings. The actual child graph preparer invokes
the existing lift producer and preserves its equations, chart support,
parameter/auxiliary layout, guards, coefficient owners and proof depth.

The existing complete-product rolling-ball producer, original numerical
constructor/evaluator and guarded DI consume these child graphs. No new shape
formula, inverse transport, root choice, solver retry or tolerance is introduced.
See [the source contract](../../Sources/CADGeometry/OriginalSourceIssuance/DESIGN.md#retained-lift-hosts-in-rolling-ball-children).

## Accepted behavioral evidence

`Verify.py` admits every input/product/log hash of the unchanged current Coons
lift evidence before compiling the changed actual caller and original numerical
rolling-ball source bodies. Overlay imports select these bodies explicitly;
retained source/lift/DI producers and numerical dependencies are receipt-bound
unchanged products. Every command has a 120-second timeout. The strict Coons WASI
runner propagates the actual WASI exit status. Successful receipts require all
four behavior markers and reject compiler/runtime error diagnostics.

`Proof.swift` checks:

- All four typed host/pcurve cases, complete closed sides, wrong-UV exclusion,
  nonmonotone pcurve with two distinct T preimages and constant-UV fibers.
- Two actual mixed rolling-ball constructions, including reversed rails; all
  128 child chart triples and sixteen knot incidents are retained. Exact graph
  XYZ/UV and positive-root conditions are checked separately from the original
  numerical evaluator's output accuracy.
- Full, strict, singleton, disconnected and complete empty requests, wrong UV and
  negative radial-root exclusion through the actual retained family and DI.
- Exact preparation/query work and storage ceilings, one-unit-short failure,
  exact retained source depth and one-less failure, foreign child binding,
  entry/final-callback cancellation and source-independent result lifetime.
- The unchanged previous Native child/lift caller fixture against the changed
  actual provider/preparer, including its resource and cancellation behavior.

constructor/evaluator, existing complete-product/lift/DI consuming path and final

polynomial/guard/child arrays remain shared. The complete-product producer imports
every child graph into its assembly field and retains original auxiliary roles.

# M2/M3 Independent Contract Verification

Swift 6.4.0 release Native and ASAN execute all 24 behavioral tests on the stable
344 declared-input snapshot. Normal WASM and matching Embedded WASM compile,
link and execute the same synchronous DomainProof body. The compiled-input
inventories distinguish the 341 portable files from the Native test sources;
each lane retains source and actual executable hashes, commands and elapsed time.
Every command has a 120-second outer process-group timeout and its own scratch path.

The new behavioral paths cover complete finite Native chart enumeration, strict,
closed, singleton, disconnected, excluded and arbitrary-size periodic requests;
exact Q(pi) ordering and rational-function arithmetic; whole line and saved-N
plane domains; every required intrinsic conic/analytic coordinate law; genuine
physical periods, signed phase, normalized arcs and nonbinary sphere poles.
Existing DI0-DI3 owner, exclusion, failure, depth, work, storage and final-cancel
proofs execute unchanged. Native task cancellation remains a Native proof;
portable synchronous execution does not claim actual parallel thread semantics.

One scoped review of the shared finite enumeration and pi implementation found
no unresolved violation. The source/analytic review found a finite arc preimage
constructed in its bounded source frame and a spurious positive family ceiling
for rank-zero inputs. Both were fixed and the concrete physical-arc and
hyperbola/parabola zero-family fixtures pass on this stable snapshot.

All new production owners are immutable Sendable values/backings; query counters,
refinements and arrays are caller-local on every target. There is no target-varying
mutable storage, synchronization, Sendable conformance or pointer escape in this
change. Existing lower contracts retain their previously verified synchronization
and failure semantics. Exact source laws retain symbolic coordinate functions;
this proof does not treat sampled trigonometric values as source equality.

Actual Curve3D/Surface3D snapshot providers, plane evaluation/UV and public Native
CS/SSI composition belong to the separate production fixture evidence. This
independent proof alone does not complete M2/M3, general XYZ publication, M4-M8,
the seven requirements, or all 87 requirements. Latest-main integration must
compare these exact input hashes before reusing these unchanged proofs.

# Exact Plane Shared-Divisor Optimization

## Scope and implementation

Base: a419b57c. L0 adds an ordered shared-divisor protocol requirement with a
source-compatible direct default. L2 shares the existing exact local inverse for
three or more numerators with a nonconstant algebraic divisor, within one scoped
invocation. The plane issuer consumes this requirement and retains every original
source, positive/squared length, orthogonality, unit length and final checkpoint
check. It never examines the field representation. No scalar solver, scalar
operation body, root proof, approximation tolerance or numeric cap was changed.

The batch admits the generated output slots; plane pre-admission is reduced from
15 to 9 slots to avoid charging U/V twice. Per-element work remains explicit.
Rational direct generation/work are unchanged. Inputs are borrowed and immutable
Array backing is retained through the existing COW handle; output arrays are new
required payloads. No measured zero-allocation or peak-memory claim is made.

## Behavioral verification

Swift 6.4.0 RELEASE, matching normal/Embedded WebAssembly SDKs,
wasm32-unknown-wasip1, Node 24.19.0 WASI Preview 1. Native and ASAN each pass 18
Swift Testing tests; the independent source suite passes 5. Native Debug, ASAN,
Native Release, normal WASM and Embedded execute the deterministic proof.
The verification graph contains only L0, L1, L2, DI0, SourceIssuer, DI and fixtures;
full CADGeometry/CADCore/L3-L6 are excluded. Build/test timeout180s, proof30s;
benchmark compile/runtime120s, each sample process30s.

New tests compare every exact quotient against individual scalar division for
one/two/three numerators, zeros and negative operands/divisors. They verify exact
work/storage nonregression for rational fields and reduced costs for sqrt(2),
independent last-work/last-storage and attained-depth refusal, entry and final
cancellation, empty input, zero divisors and foreign owners. A reducible degree6
law verifies local inverse calculations, mixed immutable computational laws,
original ordinal/multiplicity and unchanged original generator evidence; a
nonzero polynomial vanishing at the selected root remains a zero divisor.
All original 21 axial/oblique scaled-normal cases, exact basis/UV, rounded-root
refusal, off-plane refusal and lifetime/resource tests remain active.

## Release performance

Both old and new lower production graphs are built in Release. The same benchmark
source is linked to their actual modules with Swift -O. Ten paired executions
alternate old/new order, each in a fresh process. Field/root/source preparation
and ten warm-up calls are excluded; the continuous interval includes all issuer
proof checks and a fresh same-limit ledger for every call. Published basis and
UV are checked exactly outside the timed interval. Actual sources and benchmark
products are hashed. No other task-owned build or verification is started during measurement.

prepared Native Release plane issuer only, not full CS/SSI or WASM throughput.
See release-benchmark.json for every actual sample.

## Review and target ownership

One stable scoped review traces L0 default/witness dispatch, L2 applicability,
selected-root local inverses and operation-owner embedding, exact plane checks,
pre-admission and exception/terminal paths. No scoped contract finding remains.
The initial compile exposed a consuming Array iteration on a borrowing input;
it was changed to indexed access before stable behavioral verification.

| Logical state | Native / normal WASM / Embedded storage, access and lifetime |
|---|---|
| Source, scalar field, basis and coefficients | Same immutable Sendable owners and strong retention; no mutation |
| Batch output and inverse | Invocation-local Array/value; no shared mutable state |
| Caller ledger | Same exclusively borrowed noncopyable inout owner; no cross-task escape |
| L2 bridge depth | Existing synchronous scoped invocation owner; same forwarding/terminal paths on every target |

No new unsafe boundary, target-dependent state, conformance, lock, callback or
cache exists. Actual target compiler inventories and successful cost assertions
prove that the specialized witness is used on all three target modes. Existing
bridge lifetime is checked by ASAN. Historical PlaneRepairEvidence products and
caches are preserved. DI.4, legacy plane migration and seven/full87 acceptance
remain outside this optimization.

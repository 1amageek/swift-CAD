periodic offset laws and guarded all-integer DI composition. The existing finite
chart entry still refuses periodic sources. Its span/law construction is shared;
the original offset normal/root formula is reused without a second producer.

  all two/four seam/corner occurrences remain available. Canonical offset position
  accepts only the owning fundamental side. Exact original position coordinates
  and positive root equation are checked independently.
- Arbitrary-size negative cycles exceed machine Int and return unreduced authored
  parameters through the existing Native correspondence. No finite window is used.

  Singular normal subsets remain enclosed but have no offset position, including
  at distance zero. Wrong positive root, negative root and zero root are excluded.
- Existing finite offset source/domain fixtures pass unchanged: folded rational
  normal signs, owning interior knot, zero-distance singular guard, exact request
  and retained-source behavior.
- Preparation succeeds at Native work75169 / storage369716, and fails at one less
  independently. Query exact/one-less work/storage, source/chart/family/transport
  limits, invalid template/cycle arity and malformed position tuples are checked.
- False cyclic control storage is refused by the original period issuer. A foreign
  child cannot issue the offset family. A foreign parent frame is refused. Every
  parameter and the auxiliary root is checked for a foreign scalar field before
  empty/excluded selection can short-circuit.
- Entry, mid-operation and terminal cancellation propagate original direct/domain/
  source/polynomial wrappers for successful and excluded queries. No empty or
  partial success is returned. Only the final cover leaves the preparation scope;
  later position/root queries and caller COW-array mutation preserve its authority.

| State | Native / normal Wasm / Embedded storage | Access / lifetime |
|---|---|---|

No mutable shared state, unsafe pointer, unchecked Sendable or target-specific
synchronization/conformance is added. Searches and source review distinguish
computed properties from local mutable scratch. Existing scoped source-admission
borrowing is reused unchanged. New receipts have no public unchecked initializer.
Parent selection rebasing admits its required new owner-specific output intervals;
source laws, periods and Native correspondence buffers remain shared by value.

One stable scoped review checks the actual Native wrapping/owning-basis path,
source period/differential theorem, all-template key correspondence, exact request
rebasing, guarded root queries, resource charging, terminal cancellation and
retained lifetime. No production finding remains. One documentation finding was
corrected: the generic admission methods establish Embedded generic protocol
dispatch, not an existential generic-call capability. This changes no source or
runtime premise, so the accepted behavior is reused without another review/build.

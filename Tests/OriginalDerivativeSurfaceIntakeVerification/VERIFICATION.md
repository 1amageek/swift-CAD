# Retained rational derivative-surface intake

This unit implements M4.S.DS / M4.P.DS for the existing rational plane-derivative
surface construction. It intakes the source owner's draft without changing that
worktree, reuses the sealed retained-surface family/domain contracts, and adds no
second projection, tensor producer or solver. General angular/algebraic derivative
surfaces and the other M4-M8 requirements remain open.

## Production behavior and scope

`Verify.py` recompiles the actual derivative-surface constructor/query bodies,
correction/Coons atlases, new position atlas, source provider and retained source/DI
bodies in a focused adapter module. Adding imports is the only assembly transform;
compiled bytes and original production bytes are both bound. Source construction,
public point/parameterDerivatives and source-to-DI execution use the real bodies,
with receipt-admitted unchanged CAD child objects. This is not a full CADGeometry,
Kernel, L2-L6 rebuild or a test of every procedural enum dispatcher.

The cached Core/Geometry/collection modules and object inventories, imported
architecture modules, accepted original executables and runtime logs are checked
before use and afterward. Unselected old solver/identity/boundary/publication
bodies are explicitly listed in each receipt and provide no evidence for those
paths. The existing same-field DI operations used here retain their behavior;
the newer descendant-field ports are owned by the accepted M6 evidence.

| Required behavior | Actual fixture |
|---|---|
| Original position law | Weighted/unweighted Native tensor with projection/identity; exact independent expected Z and unchanged numerical point/derivatives |
| Complete cells | Four U/V cells and all four incidents at the original knot corner; original denominator and identity UV retained |
| Request restrictions | Exact rational 1/3 and 2/3 strict endpoints, disconnected requests, singleton corner, empty request |

| Lifetime/COW | Query after the original local source leaves scope; changing a copied Native control array leaves the retained law unchanged |

The source preparer and domain issuer themselves are unchanged. Their accepted
[retained-surface domain evidence](../OriginalDomainIdentityVerification/RetainedSurfaceDomainEvidence/VERIFICATION.md)
continues to own missing-cell/gap, foreign owner/frame, count/depth/transport and
other general contract counterexamples. This new actual source is additionally
run through those production contracts by the fixture.

## Findings and confirmation

One stable scoped review covers source expression/cell ownership, denominator
nonvanishing, immutable lifetime, exact request clipping, admission/failure and
portable assembly. Its concrete findings were closed before the final receipts:

- The draft fixture tried to validate an invalid full-multiplicity Native knot
  before checking constructor refusal. It now verifies the actual typed failure
  from the construction path, without treating rejection as source coverage.
- Dictionary iteration in the new coefficient transfer changed import work for
  identical snapshots. The provider uses the existing admitted canonical term
  order. Exact-budget and one-less tests now pass without deterministic-hash env.
- The initial portable fixture used a 2 GiB Int literal, outside wasm32 Int.
  All targets now use the same smaller 1 GiB fixture cap; caller ceilings are not
  relaxed. Initial bare linking also omitted the existing consumer 64 MiB WASI
  stack configuration. The final assembly binds and uses that existing setting.
- Cache admission now checks the actually imported architecture module and the
  original accepted executable, in addition to intermediate module/object/log
  hashes. Final lane receipts include those exact products.

Initial failures in `.build/m4-ds-intake-*` are diagnostic, not acceptance.
Final records are `Evidence/<lane>/receipt.json`, with the exact archived driver,
source/product hashes, bounded commands and compile/link/runtime logs.

|---|---|---|---|---|
| Source projection and original construction | Same immutable retained fields | Same | Same | Existing immutable constructor; source retained by atlas/snapshot |

| Temporary coefficients, counters and buffers | Invocation-local inout admission | Same | Same | Admitted before allocation; discarded on failure |

No changed production file contains an Embedded storage/conformance branch,
unchecked Sendable, unsafe isolation or new shared mutable state. ASAN instruments
all newly assembled bodies and fixtures; cached unchanged child objects are not
instrumented. No new parallel stress claim is made.

Swift 6.4.0 release and matching normal/Embedded SDK descriptions are bound.
Embedded uses WMO/-Onone, the matching Unicode table library and original source
bodies. Every compile/link/runtime command has a 120-second timeout. Each receipt
rechecks all admitted premises after runtime. These timings are correctness
verification, not a benchmark or whole-M8 completion.

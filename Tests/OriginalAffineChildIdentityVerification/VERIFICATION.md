# Affine Child Identity Verification

## Scope and authority

M5.A transports an existing sealed child identity through a completed M4 affine
child cover. The additive public issuer returns the existing parent identity type,
so nested covers and current relation-view operations reuse it. Full nonlinear,
singular, join and paired-source shared-boundary issuance remain M5.C. This is not
full M4-M8, automatic CS/SSI, general boundary/self acceptance or whole-seven/full87
completion. Design authority: [OriginalParameterIdentity](../../Sources/CADGeometry/OriginalDomainIdentity/OriginalParameterIdentity/DESIGN.md).

The independent graph compiles the actual current L0/L1/DI0/source/DI files and
existing authoritative reading-protocol fixtures. Native source arrays and analytic
construction inputs pass the real source-law/domain/identity issuers; the new port
adds no shape formula or solver. Actual Curve3D/Surface3D production adapters and
Kernel callers are not rebuilt or executed in this slice. Their earlier evidence
is not generalized to this new generic identity API.

## Behavioral counterexamples

- Authored reversal, exchanged axes, unequal gains, nested source types, independent
  torus periods and negative cycles of magnitude 10^36 retain every original tuple.
- A real tensor law G(u,v)=(u+v,u*v,0) supplies a whole-law declared-edge identity
  with exchanged child axes. Parent conjugation yields independently expected
  gains -3/2 and -2/3. Wrong in-scope correspondence is refuted and the original
  declared-boundary kind stays position-only.
- Sphere collapsed subsets retain all UV; near-pole tuples remain unestablished.
  Exact strict/disconnected/singleton/empty parent requests restrict both child
  scopes by full pullback. Foreign source and same-source foreign frame fail.
- Physical-radian source periods use mathematical pi. Rounded 2*Double.pi is
  refuted; foreign Q(pi) tuple values preserve incompatibleDomain through the
  public domain failure wrapper. Caller COW edits preserve retained source values.
- Original proof, child family and cover remain retained after their constructing
  scopes end. Constraint-array COW mutation cannot alter the issued proof. Rational
  relation-view reuse allocates zero generated storage.
- Preparation succeeds at work762/storage8160 bytes on Native (target-specific
  storage is recorded in each log), and fails at one-less work or storage. Source,
  transport, chart, family and identity limits remain independent. Entry/mid/final,
  successful-empty publication and subsequent-query cancellation propagate.
- An instrumented exact rational field marks the original offset with independent
  value/coefficient depth7 while canonical conjugation cancels it from final
  coefficients. Original evidence readmission accepts7 and rejects6, including
  symmetry and transitive composition. This fixture verifies admission causality;
  it is not evidence of an additional geometric coefficient capability.

## Ownership and review

| State | Native / ordinary Wasm / Embedded storage | Access / lifetime |
|---|---|---|
| Parent identity/proof | Immutable receipt and let-only proof owner | Existing query requirements; source owners retained |
| Cross-source evidence | Immutable typed child-proof/cover owner | Data-only Sendable retention; no existential methods |
| Scalar readmission | Immutable scalar/field arrays and ancestor-owner references | Same caller admission; ancestor arrays are shared |
| Scratch and admission | Invocation-local arrays and exclusive inout | No shared mutation, lock or target-dependent conformance |

No unsafe pointer, unchecked concurrency, target-specific raw state or global cache
is introduced. Only isolation-verification imports are conditional. Count/byte and
proof-depth arithmetic uses checked existing helpers. Base proofs incur no new
readmission owner; the added optional reference is included in proof-owner storage.

One stable scoped review inspected source authority, scope pullback/conjugation,
proof-kind preservation, original causal scalar/depth retention, all allocations,
final cancellation, ownership and the existing query consumers. Its sole remaining
finding was missing nonidentity child-permutation coverage. The real whole-boundary
fixture closes that finding on all four lanes; production source was unchanged by
this confirmation. No additional aggregate review is required.

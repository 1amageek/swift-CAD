# Retained-Root Extension Evidence

## Boundary

One additive L0 constructor embeds a certified original rational root into an
explicit existing parent field. All 88 prior L0/L1 sources and 55 issuer sources
remain byte-identical to 0f041e2d. Existing constructors, scalar algorithms,
L2-L6, shape targets, relation solvers and public CS/SSI were not changed or built.
Actual directed-traversal/Coons provider integration remains unfinished.

## Actual execution

Swift 6.4.0 release Native/ASAN each execute 16 tests. Native, ASAN and both
matching ordinary/Embedded WASI proof executables execute all 16 groups; each
command is bounded by 120 seconds. receipt.json binds every actual compiler
input, raw artifact and retained build/runtime log. No existing lower or issuer
input was reinterpreted as the new port's evidence.

The production constructor imports the original rational law and unique-root
selector. It calls no isolator, candidate generator or root initializer requiring
new unique-root search. Existing immutable context, local-field math and retained
domain constructor own the result. Zero/unit authority is shared from the newly
retained context, without another coefficient buffer. The selected interval and
open/closed endpoints remain verbatim; exact rational embedding preserves the
real root selected by that already-sealed certificate.

## Review and change impact

One scoped review and targeted finding confirmation closed pre-admission of both
linear degree scans and reuse of the existing domain ownership constructor.

the existing synchronous numeric admission bridge remains unchanged. Every target
uses the same new constructor, context types and immutable ownership. ASAN and
actual Embedded execution cover successful construction, lifetime and failures.

arrays. Source-provider integration will test the new boundary directly against

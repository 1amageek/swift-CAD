# Ruled Source Issuance Evidence

## Scope and execution

The [receipt](receipt.json) binds the current production and fixture inputs to
Native, ASAN, normal WASM and Embedded WASM behavior. Native and ASAN each pass
11 tests. Each standalone proof executes the same eleven fixture groups; actual
geometry adapter proofs execute weighted Native, periodic, primitive, physical
angle and heterogeneous ruled paths. Swift 6.4.0 release and matching SDKs are
fixed. Independent builds contain only L0, L1 and source issuance; no upper
geometry or solver target was built. Every command has a 120 second deadline.

## Contracts proved

The original common-U linear-V formula preserves all four homogeneous laws and
unreduced W. Child transports must prove authored U by exact cross multiplication.
Support is intersected exactly, with singleton retained and disjoint charts
rejected. Parent selections retain both complete child receipts, so source and
coefficient owners survive input mutation and release. Equal-valued foreign
bindings are rejected. Source/value/coefficient depths, independent work/storage
limits and entry/final cancellation are checked on the same exclusive ledger.

Actual `RuledSurface3D` uses a varying-weight Native spline and an analytic line;
a raw-line equivalent is also exercised. The existing raw-line validation still
requires its original unit direction. Source issuance does not normalize it.
Full coefficient comparisons prove the formula without sampled residuals.

## Review and target parity

One scoped review covers source authority, child provenance and lifetime, guards,
complete local support, resource admission and failure propagation. No outstanding
finding remains. Stored sources/selections are immutable Sendable values; local
working arrays are invocation-owned. There are no target-conditional shared state,
Sendable or synchronization variants. This proof does not claim multithreaded WASI.

Cached geometry modules reuse their recorded runtime receipt and unchanged
provider premises. Reused geometry archives are scanned member by member; every
object payload SHA-256 must match the current cached object inventory, including
multiplicity. Issuer archives use newly built inputs. Per-lane manifests record
archives, object inventories, exact commands and runtime artifacts. This avoids
recreating large unchanged geometry archives while retaining actual input checks.

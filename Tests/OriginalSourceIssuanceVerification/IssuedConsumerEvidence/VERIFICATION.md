# Issued consumer contract verification

## Scope

Finite issued-law/domain/map binding, complete L5 map-pair aggregation and exact
original TUV extraction are verified independently. This does not establish existing
public CS dispatch, family receipt migration, SSI publication or whole-seven completion.
The production numerical publisher extraction remains outside this committed snapshot.

## Execution

| Lane | Build, link and runtime | Guard wall time |
|---|---|---|
| Native | Passed | 32.365 s |
| Address Sanitizer | Passed | 88.984 s |
| Normal WASM | Passed in Node WASI | 42.146 s |
| Embedded WASM | Passed in Node WASI | 57.958 s |

Swift 6.4.0 release and matching normal/Embedded SDKs are used. Each command has
120-second timeout. Lower L0-L5/domain products were regenerated in an independent
verification package under the explicit regeneration authorization. No CADCore,
CADGeometry or Kernel target was built. Lower manifests record compile provenance;
behavioral evidence is provided by the consumer executions, not inferred from compilation.

Cases cover weighted homogeneous laws, full two-span coverage and both closed seam
owners, exact inverse selection, missing-law failure, complete exclusion, algebraic T,
identical original TUV with two retained chart incidences, different UV at one XYZ,
exact tuple ordering, mixed positive/isolated atomic rejection, result/pair ceilings,
exact work/storage boundaries, independent inherited value/coefficient depth and cancel.

## Snapshot and review

Receipts retain the actual compiled input hashes, link-object hashes and commands.
Per-lane proof text is retained. Embedded needs an explicit conditional import of the
coordinate-transfer module; adding that import does not change the non-Embedded
compiled proof path, so earlier successful non-Embedded executions are reused.
All production inputs are identical across the four final lanes. The domain proof
fixture was extended after domain-only verification; its unchanged production premises
are checked separately and its extended behavior is verified by the final map proof.

Scoped review checked owner/source correspondence, uncancelled denominator guards,
complete pair failure, original tuple grouping, retained proof depths and same-admission
allocation/work/terminal checks. Metadata uses in-place heap ordering with constant
auxiliary storage. All mutable arrays are invocation-local, all published owners are
immutable Sendable values, and no target-specific isolation or unsafe path was added.
The existing scoped admission borrow is reused; its implementation was not changed.

## Reproduction

Use VerifyFiniteIssuedPreparation.py with --lane, --lower-products and --reuse-source
for unchanged checked products, or omit --reuse-source to regenerate the independent
issuer package. The explicit lower-products path must have its matching validated
rebuild-manifest.json. CAD production targets are not built by this runner.

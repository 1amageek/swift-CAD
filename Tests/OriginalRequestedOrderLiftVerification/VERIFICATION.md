# Original requested-order lift and traversal

## Scope and authority

This unit closes PG.J for the existing finite Native/Coons/retained-correction
lift and traversal callers. It does not close a whole source family, M4-M8,
whole-seven requirements beyond the previously completed requirement 5, or full87.

The actual retained construction/root-span caller requested a surface value or
D1-D3, but the shared surface entry required order four. Removing that artificial
gate exposed a second failure: an original Native pcurve with all V controls
exactly zero returned [-6e-323,6e-323], exceeding the receiving Native/Coons support.
The pcurve owner now intersects only its value with the independently valid
positive-weight original control hull on native support. Constant-U/V endpoint
hulls and exactly constant affine coordinates retain their authored bounds.
Unknown UV is never clipped to a host; tiny nonzero/outside coordinates remain so.
Derivative coefficients, original joins, guards, owners and all caps are retained.

The shared surface/revolution entries accept requested order zero and above;
ruled/rolling-ball allocates its first V coefficient only for a positive order.
Higher requested equations are unchanged. No identity, source-equality theorem,
parameter inverse, solver fallback, tolerance change or cap increase is added.

## Independent linkage and evidence locality

Four changed source files are freshly compiled with ordinary imported original
CADGeometry argument/result types. The unchanged canonical angular leaf is compiled
with them. Generated files prepend imports and add only a fixture-specific Swift
boundary annotation at the surface and pcurve entries; stripping that annotation
recovers exact current production bytes. No production annotation or API is added.

Native links a privately copied unchanged numerical archive with only those two
symbols weakened and force-loads the fresh producer archive. WASM uses the linker's
function wrappers. Original cached archives are hash-checked and never modified.
The same actual cached public caller fails with the old source gate and succeeds
with the current body. Direct fresh-provider tests additionally exercise each
changed producer. This linkage is independent changed-source/caller evidence,
not a new full production CADCore/CADGeometry/Kernel or L2-L6 build.

Every process has a 120-second timeout. The commands retain fixed Swift6.4.0 and
matching SDKs. Inputs, generated files, copied/imported artifacts, compiler tools,
selected symbols and runtime logs are hashed before and after. Old cached source
premises are verified against f3cdb916 and retained separately; they are not asserted
to match current changed source. ASAN instruments the fresh changed assembly;
unchanged numerical caches are not newly sanitized.

assumption, value-versus-derivative separation, actual caller selection, requested
continuity, caller costs/cancel, array ownership and target behavior. No production
finding remains. The linkage description was corrected from three sources/one entry

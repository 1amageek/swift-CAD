# G01 root-free sphere-cone generalization

## Accepted scope

This closes one partial implementation unit, not G01 or any whole seven-requirement gate.
The existing full owner accepts actual sphere center/radius, cone apex, unit-Z axis and
physical half-angle when its source proves two distinct roots over the whole circle.
The former numeric recipe remains a regression input. New inputs include an apex inside
a translated sphere and a pair whose two full branches both have negative slants.
Both input orders, two ordered roots, both circle charts and chart endpoints retain
original XYZ and both UV families. The exact sphere metric, latitude and azimuth
arguments are checked. Original support, independent integer lifts and proof owners
are retained; the public old full fixture checks huge cycles, incident seams,
foreign bindings, detached result use and independent query admission.

The source theorem is authoritative in
[OriginalSourceIssuance](../../../../Sources/CADGeometry/OriginalSourceIssuance/DESIGN.md#g01-root-free-sphere-cone-family-consumption).
A Cauchy bound from actual coefficients bounds the upper root; the source-proved
midpoint separates it from the lower root. Vieta retains the second root without
another decomposition. No work/storage/depth cap or equality tolerance was increased.

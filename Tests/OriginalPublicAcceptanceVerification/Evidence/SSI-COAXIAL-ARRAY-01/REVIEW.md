One comprehensive review follows the previously delivered source/family through
originalCoaxial array publication, interval views, member scope, resource ownership,
all six public entries, prepared reuse, serialization, and changed legacy consumers.
The producer creates no coefficient law, solver or new source proof. Each cover
piece retains the same immutable relation and branch/interval ordinals. Constructor
is internal and checked; external callers cannot manufacture proof objects.

Per-piece phase inclusion is checked before the existing member query validates
both retained source UV requests and arbitrary independent indices. Singleton
image0 and interval image1 remain distinct; fiber0 retains discrete infinite lifts.
No XYZ distance, rounded circle, sample, hash or owner identity proves geometric
identity. Hashable compares the proof owner/ordinals only. Exact symbolic position
retains original height/radius/source frame. Rich and bare arrays share that owner;
no branch/request array is copied per piece. Complete empty remains proof-bound.

payload and reserves before append. Full/empty/three-piece N/N-1 work/storage and
capacity3 are verified. No cap or tolerance is increased. Finding confirmation
is limited to F1 and the changed resource path after this scoped review.

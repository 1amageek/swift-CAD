## Scope and authority

The additive source prepares ordered original Euclidean polylines once each in
explicitly retained ancestral coefficient contexts. The final immutable field can
import every earlier child coefficient through the unchanged exact ancestry
contract. Equal input values retain separate source owners. The existing individual
provider initializer keeps its independent-field behavior. Formula, root selection,
normalization, original parameter meaning and scalar arithmetic remain unchanged.

## Behavioral evidence

Two distinct authored polylines have independently checked first stations:
s^2+2s-1=0 with 0<s<1/2, and 4s^2-10s+5=0 with 1/2<s<1.
A third equal-input polyline retains a separate owner. Every original positive
segment/index and exact endpoint law survives import into the final field.
The actual existing Native, Coons and boundary-correction lift producers consume
each prepared child with final-field host charts and the child's retained pcurve
charts. Complete twelve/eight products, eight/four closed join incidents, exact
T/UV/XYZ, singleton selection and wrong-UV exclusion pass. The prior finite,
periodic and retained-atlas public-point/domain fixtures run unchanged.

affine parameter curve contract end-start>distance. Correct authoring keeps
range0..1 and uses origin(1,1/2), direction(-1,-1/2), preserving exactly the
intended independent reversed polynomial and every derivative assertion.

The first resource fixture already passes exact N and each separate N-1.
Only its last exhausted-both-caps retry expects the wrong first failure.

next work charge; exact storage failure is therefore required. The corrected
fixture retains identical N, both limits and both unchanged snapshots, without
an allowance, padding, arbitrary error acceptance or production change.

# Current OS Source and Plane Offset Callers

## Scope

This unit applies the package's macOS 27 / iOS 27 / visionOS 27 baseline to
existing source consumers and closes the actual bare-plane offset feature
input. Swift 6.4.0 and its matching SDKs are fixed. This is neither complete U1
nor a completed shape family or whole intersection requirement.

The [raw evidence index](index.json) owns exact source, toolchain, SDK, command,
module/object, fixture, runtime-log and receipt bindings. Historical attempts
are retained as diagnostics, separately from accepted final executions.

## Changed Paths

| Owner | Change and invariant |
|---|---|
| Geometry / IR source consumers | Remove earlier Apple OS guards and fallback implementations; retain the current successful bodies and actual target capability boundaries. |
| Original plane offset | One exact source-owned displacement predicate gates both materialization and parameter-curve image validation. |
| Document memo | Keep completed-value publication under the same Mutex on every target; computation and caller callbacks remain outside the lock. |
| Portable IR | Only the largest bridge operation payload becomes indirect; preserve value equality, Hashable, Sendable, explicit codecs and source fingerprint semantics. |
| IR target adapters | Direct dependency imports, the existing real cancellation checker, exhaustive stable reference keys and direct collection accessors replace unavailable target mechanisms. |
| Verification runner | Reuse only receipt-matched Core products while generating changed Geometry independently; changed IR reuses the unchanged Core/Geometry/Topology prefixes. |

The plane predicate uses exact rational values of authored binary64 inputs,
including exact origin subtraction. It proves displacement parallel to the
original oriented differential normal, squared length equal to distance squared
and the requested side. Authored U uses U cross (N cross U); an absent U retains
the source basis convention. Zero distance retains source guards. Rounded or
invalid materialized candidates retain the original procedural definition;
unequal images are rejected rather than approved by residual tolerance.

Bridge authoring and rewriting allocate compiler-owned immutable storage;
ordinary enum copies and reads share it. This authoring allocation is not
reported as geometry-query storage. Other seventy operation cases stay inline.
The clock preserves its reference epoch, nanoseconds and typed unavailable-clock
failure. Cancellation remains the actual current task's CancellationError.

# Native Domain Consumer Composition

## Scope
Changed production Native source providers and public CS/SSI parameter consumers
are compiled directly against fresh L0-L5, SourceIssuer and DI. Unchanged Native
DTO/intersector objects are reused only after their runtime artifact and provider
premises match PublicReviewFixEvidence. This is not a fresh full CADGeometry build.

## Behavior
Native, ASAN, normal WASM and Embedded WASM execute the same actual public fixture
bodies: weighted crossing, tangent/repeated contact, continuous overlap, distinct
UV, endpoint/singleton, disjoint request, geometric exclusion, source lifetime,
SSI curve/coincidence/empty and folded SSI (45 cells, 108 attachments).
Requests, effective selections and full finite-cover ownership are checked on
public results. Independent input/work/storage/depth/cell/component and final
point/empty cancellation failures propagate. Original ceilings are unchanged.

## Toolchain and Limits
Swift 6.4.0 release and matching normal/Embedded SDKs; wasm32-unknown-wasip1;
Node 24.19.0. Every build, compiler, link and runtime command has a 120s timeout.
Embedded is compiled with mandatory WMO at default Onone. Exact commands, compiler
identifiers, input hashes, module objects and executable hashes are lane-bound.

## Review
One scoped review followed by specific confirmation found and closed admission
of temporary selected interval buffers before allocation. Native adapter domains
have one chart, zero families and an identity/inverse word depth two; scalar and
coefficient budgets remain caller-owned. Source validation precedes indexed access.
There is no new shared mutable state, conditional synchronization, unsafe owner,
solver fallback, repeated source preparation or source equality inferred from XYZ.

## Preserved Gaps
Native public XYZ migration, boundary/self-contact consumers, remaining source
families and legacy stored-N plane evaluation/UV migration remain DI.4 work.
The foundation checkpoint is commit 0b52e18c; its retained evidence describes
that source snapshot, while this directory binds the changed consumer composition.

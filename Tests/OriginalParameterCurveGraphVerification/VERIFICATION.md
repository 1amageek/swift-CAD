# Original parameter-image and traversal curve graphs

## Scope and authority

This evidence owns complete finite curve-graph composition through original affine
parameter images and retained directed traversal, and consumption by the existing
rolling-ball product and guarded DI. It does not complete a whole source family,
M4, M5, M6, M7, M8, any additional whole-seven requirement, or full87.

Production authority is the original map reader, retained endpoint producer and
sealed child source/coverage. The implementation adds relational pullback rather
than a child inverse. All original child parameters become auxiliaries; child XYZ,
all guards, closed/open local bounds, denominator exclusions, owner and attained
depths survive. The parent parameter remains T. The normalized rolling-ball API
still requires exact [0,1]; internal finite children retain authored Native support.
The spatial-word coverage Children view is correspondingly generalized to the
sealed finite family, preserving the existing readers and normalized outer API.

## Stable review and finding confirmation

One scoped stable review found the assumption that child parameter transport is
always univariate. The correction distinguishes univariate local-parameter
polynomials from full graph-variable polynomials and checks polynomial/map arity.
The original univariate embedding and equation remain unchanged. Finding-only
confirmation exercises auxiliary-dependent transport and a non-leading parameter
layout; the whole aggregate review is not repeated.

The four initial full receipts bind the exact reviewed bytes. Their four changed
premises are retained byte-for-byte in Evidence/review-snapshot, with equality to
the original accepted hashes checked before archival. Those old receipts are not
asserted to match current changed files. Evidence/acceptance.json composes these
unchanged full-path results with four current-source finding-final receipts.

The first finding runner used CommandLine: Native/ASAN succeeded, normal WASI ran
the full fixture because its launcher did not forward the argument, and Embedded
failed compilation because CommandLine is unavailable. These logs are diagnostic,
not final acceptance. A shared ORIGINAL_PARAMETER_GRAPH_FINDING compile flag now
selects the same finding body on every target. Only *-finding-final receipts are
accepted for the current fixture/runner. Earlier diagnostic directories are kept.

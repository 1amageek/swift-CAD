# Retained Atlas Host Native Pcurve Lift Verification

## Scope and contracts

M4.S.LN connects actual retained rational host atlases and original rational
B-spline pcurves through the existing finite lift producer and guarded DI. The
source binds the original SurfaceLiftCurve3D, host and pcurve; every authored
pcurve span survives. The producer's existing offset/span maps normalized T to
that original knot domain. No new position formula, fitted curve, inverse,
chart partition or unchecked certificate is introduced.

Design authority: [source](../../Sources/CADGeometry/OriginalSourceIssuance/DESIGN.md#retained-atlas-hosts-with-native-pcurves)
and [DI](../../Sources/CADGeometry/OriginalDomainIdentity/OriginalDomainCoverage/DESIGN.md#retained-host-native-pcurve-domain-consumption).
Actual host coverage in this fixture is boundary correction. Plane-derivative
actual Surface3D routing, general/nonrational pcurves/hosts, priority images,
out-of-support hulls requiring complete restriction, M5/M6/M7/M8 and whole-family
completion remain open. Whole-seven remains 1/7; full87 remains incomplete.

## Execution and receipt locality

Swift 6.4.0 release, matching ordinary/Embedded SDKs and generation-bound numerical
children are admitted through the retained source/DI plans. Four paths run per target:

- VerifyActual.py freshly compiles current source, DI and original boundary
  adapters on the admitted numerical ABI, and executes actual corrected hosts with
  Native pcurves plus every unchanged actual retained-host fixture. Native final
  fixture compilation reuses only an identical successful adapter command after
  current-source/generated-header/product/log checks; the superseded fixture run
  is not current acceptance.
- Verify.py freshly compiles current independent source/adapters and DI0/DI with
  unchanged receipt-bound L0/L1 and numerical children. Existing retained-host,
  Native, finite and periodic source/domain regressions execute again.
- VerifyDepth.py reuses those current independent products and freshly links the
  unchanged inherited-depth counterexamples. Source modules are not rebuilt.
- VerifyCaller.py compiles eight unchanged original caller/Native-curve adapters
  against current retained-lift products, then links and runs the actual
  DefaultOriginalRollingBallCurveGraphPreparer retainedLift branch. Headers only
  select the admitted module/type owners; algorithm bodies are unchanged.

No broad CADCore/CADGeometry/Kernel or L2-L6 production target is rebuilt.
ASAN instruments changed source/adapters/DI/fixtures and the selected caller;
retained numerical children are not instrumented. This is not full-production ASAN.
Compile/link and supplemental runtimes have 120s limits; main source fixture
runtimes have 180s limits. Separate scratch paths preserve products. All accepted

## Behavioral evidence

- Actual zero-correction multi-cell and nonzero-correction hosts use original
  boundary-issuer traversals. No independently reconstructed sameXYZ source is
  substituted. Original lift and both child bindings are retained.
- Weighted degree-one pcurves have authored knots [2,2,3,5,5]. The interior knot
  maps exactly to normalized T=1/3. All eight host/pcurve incidents survive there;
  endpoint, interior and singleton selections preserve their exact sides.
- Forward, reversed and constant-UV pcurves retain the entire T domain and fiber.
  Exact graph XYZ is compared with an independently derived rational source law;
  public point is checked separately against its numerical midpoint accuracy.
- Wrong UV, foreign binding/host and tolerance-only support clamps are refused.
  Empty selected requests remain guarded complete enclosures; they are not proof
  that the original shape has no position outside a guessed box.
- Source/child preparation, shared lift preparation and incidence succeed with
  measured exact work/storage and fail with one less. Entry/final storage
  cancellation, source depth and product chart limits fail explicitly.
- Unchanged depth fixtures succeed at attained inherited value/coefficient
  ceilings and refuse one less during preparation and readmission.
- The existing rolling-ball child caller consumes the changed shared retained
  lift family, preserving every Native knot side and the typed pcurve view.
  Exact caller work/storage and entry/final cancellation are verified.
- A detached new family still admits original T/UV after loop-local host, pcurve,
  source and prepared children are released. Existing Native/periodic ownership,
  field and lifetime counterexamples execute from current source products.

qualification, superseded fixture run, missing selected caller adapters and
SDK/import assembly repairs. They are not accepted runtime evidence. Native
successful adapter compile reuse is distinguished from its superseded fixture.

comparison before and after fresh Native/Embedded source/DI, actual, depth and
caller processes, protected foreign HEAD/status/index/drafts and publisher patch,
